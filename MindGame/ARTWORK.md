# Bundled artwork

Created with the built-in image-generation tool for this project, then split and optimized into WebP atlas cells. Native boards, game values, clues, buttons and interactions are drawn/laid out by Android code.

Final assets: `app/src/main/assets/art/desk_0.webp` through `desk_6.webp`, `wood.webp`, `relic_0.webp` through `relic_15.webp`; launcher art: `app/src/main/res/drawable-nodpi/owl_icon.png`, with adaptive resources in `mipmap-anydpi-v26/`.

## Relic atlas prompt

Use case stylized-concept. Production Android game asset atlas, square 1024x1024, exactly 4 columns x 4 rows equal square cells, sixteen individually centered antique relic illustrations on pale ivory parchment. NO text NO labels NO grid outlines. Consistent top down product illustration, ornate realistic brass, dark walnut and teal gemstone palette, warm light, detailed tactile adult museum treasure art. Reading left to right top to bottom: compass, ornate key, hourglass, brass telescope, ancient coin, wax seal, quill with inkwell, folded map, pocket watch, scarab amulet, sextant, oil lamp, carved chest, old book, crystal vial, golden feather. Each object fully inside its own cell with 15% padding and no overlap. Uniform pale cream background, crisp distinct silhouettes for a memory matching game. Not emoji not cartoon.

## Desk atlas prompt

Use case stylized-concept. Android game production artwork atlas landscape 1536x768, exactly FOUR columns and TWO rows equal rectangular cells. Each panel self-contained framed warm ivory parchment on walnut table, with 8% blank border inside cell. No text no words no lettering. Adult premium illustrated museum objects top down, ornate brass, carved wood, teal/terracotta ceramic. Order left to right top to bottom: 1 wooden mechanical number code wheels with loose clue papers, 2 wooden mastermind board with four ROUND colored pegs and six palette pegs, 3 three ivory relic memory cards showing compass key hourglass, 4 intricate teal gold terracotta owl ceramic mosaic in antique square frame, 5 ivory sudoku paper grid with fine lines and a pencil NO numbers, 6 square minesweeper grid with brass flags, 7 four ceramic tiles embossed 2 0 4 8, 8 empty dark rich walnut wood grain texture unobstructed. Realistic rich materials and warm lighting, equal panel boundaries, no UI buttons no screen mockups no phone border.
