## Production prompt

Use case: precise-object-edit. Asset type: production artwork background for a native Android illustrated puzzle library, NOT a UI mockup. Edit the supplied approved Explorer's Desk image. Preserve the EXACT overall tabletop composition, the seven game objects, their relative positions, proportions, orientations, shadows, color palette and rich tactile detail. One continuous dark walnut tabletop, no separate card backgrounds. Preserve the upper-left brass armillary globe, loose parchment maps behind the cipher, upper-right book and inkwell, scattered leaves, small ceramic pieces, pencil and brass tools near the bottom. Preserve central objects: upper-left wooden cipher machine on loose papers; upper-right small wooden Mastermind peg board; middle-left overlapping compass/key/hourglass relic cards; middle-right framed teal/gold owl mosaic with a brush; lower-left Sudoku paper and pencil; lower-middle small square Minesweeper board with brass flags; lower-right four tactile ceramic tiles embossed 2,0,4,8. Retain existing physical parchment nameplates underneath these objects, but make ALL those nameplates blank. Retain the walnut title header, small owl badge space, brass title plaque, upper-right circular brass settings button, ornate pale parchment resume tray, small square resume picture frame and dark teal oval resume button, and bottom wooden navigation rail, but REMOVE every UI word, heading, text label, time, progress bar, navigation icon, settings gear glyph and resume thumbnail. These blank surfaces will get live native Android text, icons and controls. Keep the decorative frame and scene only. The printed puzzle numerals and mechanical cylinder symbols within objects are artwork; preserve those. Keep object sizes and locations extremely close to the reference. Expand only tiny margins to produce a clean portrait asset approximately 1024x2048, sharp high-quality fine textures and consistent warm lighting. Never turn the game objects into uniformly framed cards or a generic rectangular grid. No phones, no outer presentation margin, no sample labels, no footer caption. This is the actual scene art that will be bundled into the APK.

## Native implementation

`ui/ExplorerDesk.kt` preserves one scene coordinate system with uniform scaling. Seven physical object regions, settings, resume, Library, Collection and Stats are independently focusable native Android controls. Names, elapsed time, progress and icon glyphs are drawn from live state. Press light is native animation. No web surface or rasterized substitute for game screen logic is involved. The comparison screenshot is a real render of this native view code; the left column remains the approved concept image.

Scene art was reconstructed at higher resolution; it is not claimed to be pixel-identical to the original generated concept. The first-screen build is pending user approval.
